# ドキュメント

## ドキュメントの作成

- コードを記述した後に、`docs/content/docs/` に mdx ファイルを作成するか、既存の mdx ファイルに追記して、ドキュメントを作成してください。
- ページを追加した場合は、同じディレクトリの `meta.json` の `pages` にも追加してください。
- 文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも通常の文章の文体 (です・ます調) で記載してください。
- 見やすくするために、icon を付けることが推奨されますが、最上位のみにしてください。Fumadocs の icon (Lucide のアイコン名) を利用してください。新しいアイコンを使う場合は、`docs/src/lib/source.ts` の `icons` にも追加してください。
