# PluginName

PluginName は、morinoparty の Minecraft プラグインテンプレート [PluginTemplateKt](https://github.com/morinoparty/PluginTemplateKt) から作成したプラグインです。
Paper と Velocity の両方に対応したマルチモジュール構成になっています。

## 特徴

- マルチモジュール構成 (`common` / `paper` / `velocity` / `api`)
- Paper と Velocity の両対応
- [Cloud](https://github.com/Incendo/cloud) によるコマンド定義と [Koin](https://insert-koin.io/) による依存性注入
- 依存ライブラリを JAR に同梱せず、Paper に実行時に取得させる軽量な JAR ([実行時ライブラリ](/docs/development/runtime-libraries))
- [fukurou](https://github.com/morinoparty/fukurou) による、実際のサーバーとクライアントを使った in-game テスト ([In-game テスト](/docs/development/game-test))
- プルリクエストごとのプレビュー (JAR、ドキュメント、テストレポート)

## はじめに

テンプレートからプラグインを作成し、ビルドして動かすまでの手順は [Getting Started](/docs/introduction/getting-started) を参照してください。
