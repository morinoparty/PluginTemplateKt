# In-game テスト (fukurou)

このテンプレートでは、[fukurou](https://github.com/morinoparty/fukurou) を使って、実際の Paper サーバーとバニラクライアントでプラグインを動かすテストを GitHub Actions 上で実行します。
テストはプレビュー用のワークフロー `.github/workflows/preview.yml` の中で、プルリクエストごとに実行されます。
`build-gradle` ジョブが作成した JAR をそのまま使うため、テストのために Gradle のビルドをやり直すことはありません。

## 構成

| ファイル | 役割 |
|---------|------|
| `.github/workflows/preview.yml` | `game-test-versions` ジョブで対象バージョンを解決し、`game-test` ジョブで fukurou を実行し、`game-test-site` ジョブで結果のビューアーを作成する |
| `game-test/fukurou.yml` | テストスイート。シナリオの場所と参加するプレイヤーを定義する |
| `game-test/scenarios/*.json` | 1 ファイルが 1 テスト。ファイル名がテスト id になる |

## fukurou のバージョン

`preview.yml` では fukurou のアクションのうち `morinoparty/fukurou/versions`、`morinoparty/fukurou`、`morinoparty/fukurou/ui` の 3 つを使い、すべて同じコミット (v2.2.1) に固定しています。
更新する場合は、3 か所の SHA とコメントのバージョンをそろえて書き換えてください。

```yaml
- uses: morinoparty/fukurou@d2834e454bd6541db83bb646465f3ef565b0675c # v2.2.1
```

## 対象バージョン

`paper-plugin.yml` の `apiVersion` が `26.2` のため、テスト対象は 26.2 以降のバージョンです。
バージョンは `game-test-versions` ジョブで `morinoparty/fukurou/versions` アクションを使って解決し、バージョンごとにマトリクスジョブとして実行します。
既定では Paper の `STABLE` ビルドがあるバージョンだけが対象になります。

```yaml
- uses: morinoparty/fukurou/versions@d2834e454bd6541db83bb646465f3ef565b0675c # v2.2.1
  id: versions
  with:
    minecraft-version: 26.2-
```

## テストスイート

`game-test/fukurou.yml` では、シナリオファイルの場所と、テストに参加するプレイヤーを定義しています。
`Alice` はオペレーター権限を持った状態で参加します。

```yaml
scenarios:
  - scenarios/*.json # 1 ファイルが 1 テスト。テスト id はファイル名 (拡張子なし)
players:
  - { name: Alice, op: true }
```

各テストは同じサーバーセッションの中で順番に実行され、テストの前にはプレイヤーの位置やゲームモード、周囲のブロックがリセットされます。

## シナリオの例

`game-test/scenarios/hello.json` では、プレイヤーが `/pluginname` を実行し、クライアントのログにチャット `Hello from PluginName!` が出力されるまで最大 10 秒待ってから、スクリーンショットを撮影します。
コマンド名やメッセージを変更した場合は、このシナリオも合わせて変更してください。

```json
{
  "name": "/pluginname replies with a greeting",
  "steps": [
    { "on": "Alice", "action": "chat", "text": "/pluginname" },
    { "on": "Alice", "action": "wait_for_log", "pattern": "\\[CHAT\\] Hello from PluginName!", "timeout": 10 },
    { "on": "Alice", "action": "screenshot", "name": "hello" }
  ]
}
```

### 主なステップ

| `on` | `action` | 内容 |
|------|----------|------|
| `server` | `command` | サーバーのコンソールでコマンドを実行する |
| プレイヤー名 | `chat` | チャットを開いてテキストを送信する (コマンドも送信できる) |
| プレイヤー名 / `server` | `wait_for_log` | クライアント / サーバーのログが正規表現に一致するまで待つ (`timeout` の既定値は 60 秒) |
| プレイヤー名 / `server` | `assert_no_log` | ログが正規表現に一致したら失敗にする |
| プレイヤー名 | `screenshot` | スクリーンショットを撮影する (比較はせず、ビューアーで確認するためのもの) |
| なし | `wait` | 指定した秒数だけ待つ |

ほかのステップや、`parallel` / `repeat` ブロックなどの書式は [fukurou の README](https://github.com/morinoparty/fukurou/blob/v2.2.1/README.md#scenario-format) を参照してください。

## タイムアウト

`game-test` ジョブの `timeout-minutes` は 15 分です。
fukurou のドキュメントでは、`10 + (isolation: reset のテスト数) + 4 × (isolation: fresh-server のテスト数)` 分を目安としています。
シナリオを増やした場合は、この値も見直してください。

## 結果の確認

全バージョンの結果は 1 つのビューアーにまとめられ、プレビューのコメントの「🦉 In-game Tests」列の「Viewer」から開けます。
ビューアーでは、各テストの結果、スクリーンショット、サーバーとクライアントのログを確認できます。
また、`result.json` を含む生の結果は `fukurou-paper-<バージョン>` という名前のアーティファクトとしてもアップロードされ、各テストの結果はジョブのサマリーにも表示されます。

## ローカルでの検証

シナリオの書式は、次のコマンドでサーバーを起動せずに検証できます ([uv](https://docs.astral.sh/uv/) が必要です)。
CI と同じ結果になるように、バージョンを固定して実行してください。

```bash
uvx --from git+https://github.com/morinoparty/fukurou@v2.2.1 fukurou validate --suite game-test/fukurou.yml
```
