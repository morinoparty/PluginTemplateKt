# ドキュメントサイト

このドキュメントサイトは `docs/` にある単独の pnpm プロジェクトです。
[Fumadocs](https://fumadocs.dev/) を [TanStack Start](https://tanstack.com/start) の上で動かし、[Vite+](https://viteplus.dev/) (`vp`) で開発サーバーの起動、ビルド、フォーマット、リントを行います。
ビルドではすべてのページをプリレンダーし、静的サイトとして `docs/out` に出力します。

## コマンド

| コマンド | 内容 |
|---------|------|
| `pnpm dev` | 開発サーバーを起動する (`vp dev`、`http://localhost:3000/docs/`) |
| `pnpm build` | 静的サイトを `docs/out` に出力する (`vp build`) |
| `pnpm preview` | ビルドしたサイトを確認する (`vp preview`) |
| `pnpm check` | フォーマットとリントを行い、修正できるものは修正する (`vp check --fix`) |
| `pnpm check:ci` | フォーマットとリントを検証する (`vp check`) |
| `pnpm typecheck` | 型チェックを行う (`tsc --noEmit`) |

リポジトリ直下からは `task docs` (`pnpm install` + `pnpm dev`) と `task docs:build` (`pnpm install` + `pnpm build`) でも実行できます。
`docs/` を変更した場合は、`pnpm check:ci`、`pnpm typecheck`、`pnpm build` が通ることを確認してください。

## 構成

| パス | 役割 |
|------|------|
| `content/docs/` | ドキュメント本文 (MDX) とサイドバーの構成 (`meta.json`) |
| `src/routes/` | TanStack Start のルート (ドキュメントページ、検索インデックス、`llms.txt` など) |
| `src/lib/shared.ts` | サイト名、GitHub リポジトリ、Modrinth の URL |
| `src/lib/source.ts` | Fumadocs のソースの定義と、サイドバーで使うアイコンの対応表 |
| `src/styles/` | Tailwind CSS (fumadocs-ui) と Chlorophyll のデザイントークンの CSS |
| `vite.config.ts` | Vite+ の設定 (プラグイン、プリレンダー、フォーマット、リント) |
| `pnpm-workspace.yaml` | Vite+ のバージョン (catalog) と pnpm の設定 |
| `panda.config.ts` | Chlorophyll のプリセットからデザイントークンを生成する Panda CSS の設定 |
| `source.config.ts` | すべての MDX に共通する remark プラグインの設定 |
| `public/` | そのまま出力される静的ファイル (トップページの転送用 `index.html`、Dokka の出力先 `dokka/`) |

`src/routeTree.gen.ts` はルートから自動生成されるファイルです。手で編集しないでください。

## ページの追加

1. `content/docs/` の該当するディレクトリに MDX ファイルを追加します。
2. 同じディレクトリの `meta.json` の `pages` にファイル名 (拡張子なし) を追加します。

MDX では、`mermaid` のコードブロックで図を描けるほか、`:::note` や `:::warning` などのディレクティブで注意書きを表示できます。

### アイコン

`meta.json` の区切り (`---[Rocket]はじめに---` など) やページのフロントマターでは、[Lucide](https://lucide.dev/icons/) のアイコンを名前で指定できます。
ただし、ブラウザに読み込むアイコンを減らすために、使えるアイコンは `src/lib/source.ts` の対応表に登録したものだけにしています。
新しいアイコンを使う場合は、対応表に追加してください。

```ts
// src/lib/source.ts
import { Hammer, Rocket } from "lucide-react";

const icons = { Hammer, Rocket };
```

## デザイン

色のデザイントークンは、morinoparty のデザインシステム [Chlorophyll](https://github.com/morinoparty/Chlorophyll) (`@morinoparty/chlorophyll-react`) のものを使っています。
`panda.config.ts` で Chlorophyll の Panda CSS プリセットからトークンだけを取り出し、CSS 変数 (`--mpc-colors-mori-*` など) として出力しています。
コンポーネントは fumadocs-ui のものを使い、色をこれらの CSS 変数で上書きしています。ダークモードは提供せず、ライトテーマ固定です。

## 公開先と BASE_PATH

| 公開先 | ワークフロー | 配置するパス |
|--------|-------------|-------------|
| GitHub Pages | `deploy_docs.yml` (main への push で `docs/` が変更されたとき) | Pages の公開パス (`actions/configure-pages` の `base_path`。カスタムドメインならルート、`https://<owner>.github.io/<repo>/` なら `/<repo>`) |
| プレビュー (S3) | `preview.yml` (プルリクエスト) | `/PluginName/<コミット SHA>/docs` |

サブパスに配置する場合は、ビルド時に環境変数 `BASE_PATH` を指定します。リンクやアセットの URL、検索インデックスの URL にこのパスが付きます。

```bash
BASE_PATH=/PluginName/abc1234/docs pnpm build
```

## 出力されるファイル

| パス | 内容 |
|------|------|
| `index.html` | `docs/` へ転送するページ (`public/index.html`) |
| `docs/**/index.html` | 各ドキュメントページ |
| `api/search.json` | 検索インデックス (検索はブラウザ内で行う) |
| `llms.txt` / `llms-full.txt` | LLM 向けのページ一覧と全文 |
| `404.html` | 存在しない URL で GitHub Pages が返すページ (`src/routes/404.tsx`) |
| `dokka/` | Dokka の API ドキュメント (`./gradlew dokkaGenerate` で `public/dokka` に生成した場合) |
